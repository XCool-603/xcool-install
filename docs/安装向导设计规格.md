## 3. 步骤条

5 步（安装）/ 3 步（卸载）。横向等距分布，圆点之间用 1px 连接线。

| 状态 | 圆点 | 文字 |
|---|---|---|
| 已完成 | 20×20 实心 `#52C41A` + 白色勾 | 13F `#4B5563` |
| 当前 | 20×20 实心 `#1677FF` + 白色数字 | 13F Bold `#1677FF` |
| 未到 | 20×20 白底 + 1px `#D0D5DD` 描边 + 灰数字 | 13F `#9CA3AF` |

连接线：已完成段 `#52C41A`，未完成段 `#E5E8EF`。

**卸载向导**：当前色换成 `#D5303D`，已完成仍是绿色。

## 6. 各页内容

### 6.1 欢迎（688×712）

- 标题：`欢迎使用「{产品名}」安装向导`
- 正文两段
- **信息卡**（`#F5F7FA`，圆角 12）3 行：默认安装位置 / 需要磁盘空间 / 版本与发布者
  每行：24×24 图标 + 11F 灰标签 + 13F 值
- **黄色提示条**：`ⓘ 下一步需要先阅读并同意「许可协议」，点击「下一步」继续。`
- 底栏：`第 1 步，共 5 步` + `[取消] [下一步 →]`

### 6.2 许可协议（688×1012）

- 标题：`许可协议`
- 副标题：`请仔细阅读下面的许可协议。安装「{产品名}」前，你需要接受本协议的全部条款。`
- **白底描边卡片**（1px `#E5E8EF`，圆角 12）内含许可正文，可滚动
- **勾选行**（`#F5F7FA` 圆角 12）：复选框 + `我已阅读并同意「{产品名}」许可协议` + 11F 灰提示
- 底栏：`第 2 步，共 5 步` + `[取消] [← 上一步] [下一步 →]`
- **未勾选时「下一步」禁用**

### 6.3 安装设置（688×923）

- 标题：`选择安装位置与附加任务`
- 副标题：`确认安装目录，并勾选安装时需要一并完成的操作。`
- **安装位置**（带图标的小节标题）
  - 输入框（左侧文件夹图标）+ `[浏览]`
  - 提示：`所需空间 X · C 盘可用 Y`
  - **快捷路径 chips**：Program Files / Program Files (x86) / 本地 AppData / D:\Program Files
- 分隔线
- **附加任务**（带图标的小节标题）
  - 2×2 **任务卡**（`#F5F7FA` 圆角 12，复选框 + 图标 + 12F Bold 标题 + 11F 灰描述）
  - `为所有用户安装` 复选框 + 灰提示
- **浅蓝信息条**：`ⓘ 将安装到 {路径} · 已选择 N 项附加任务`
- 底栏：`第 3 步，共 5 步` + `[取消] [← 上一步] [⬇ 安装]`

### 6.4 正在安装（688×720）

- 标题：`正在安装「{产品名}」`
- 副标题：`安装程序正在解压并写入文件，请不要关闭窗口或关机。`
- 进度行：`⟳ 正在解压文件`（左）+ `62%`（右，蓝色）
- **进度条** 8 高，圆角 4，填充 `#1677FF`
- **统计卡**（`#F5F7FA`）：第一行 `正在写入：bin\...`，下面 4 列：
  `已解压文件 123/199` | `已写入大小 56.4 MB / 90.6 MB` | `已用时间 00:12` | `预计剩余 约 8 秒`
- **步骤列表**：`✓ 准备安装目录 —— 已完成`（绿）/ `⟳ 解压程序文件 —— 进行中 62%`（蓝）/ `○ …—— 等待中`（灰）
- 底栏：`第 4 步，共 5 步 · 安装中请勿关闭窗口` + `[取消] [⟳ 安装中…]`（禁用）

### 6.5 安装完成（688×584）

- 左侧 64×64 **绿色圆 + 白色大勾**
- 标题：`「{产品名}」安装完成`
- 副标题：`已成功安装到 {路径}，共写入 N 个文件、X MB。`
- **绿色标签 chips**：`✓ 桌面快捷方式` `✓ 开始菜单` `✓ 安装后自动运行`
- **勾选行**：`立即运行「{产品名}」` + `点击「完成」后将自动启动程序`
- 灰提示：`ⓘ 如需卸载，可在「设置 → 应用 → 已安装的应用」中找到「{产品名}」。`
- 底栏：`第 5 步，共 5 步 · 安装已完成` + `[📁 打开安装目录] [完成 ✓]`

### 6.6 确认卸载（688×764）

- 头部：`卸载向导 · 版本 1.0.0`
- 步骤条 3 步，当前为**红** `#D5303D`
- 标题：`卸载「{产品名}」`
- 副标题：`卸载程序将移除「{产品名} {版本}」的程序文件、快捷方式与注册表项。`
- **信息卡** 3 行：当前安装位置 / 占用磁盘空间 / 安装时间与版本
- **复选框**：`同时删除用户配置与缓存数据` + 灰提示
- **红色警告条**：`⚠ 卸载后程序将无法启动，桌面与开始菜单的快捷方式也会一并移除。如需重新使用，请再次运行安装包进行安装。`
- 底栏：`第 1 步，共 3 步` + `[取消] [🗑 卸载]`（红底 `#D5303D`）

### 6.7 正在卸载（688×720）

同「正在安装」，主色换 `#D5303D`：
- `正在删除程序文件` / 统计卡用「已删除文件 / 已释放空间」
- 步骤列表：结束关联进程 ✓ / 删除程序文件 ⟳ / 移除桌面与开始菜单快捷方式 / 清理注册表与卸载信息
- 底栏：`第 2 步，共 3 步 · 卸载中请勿关闭窗口` + `[取消] [⟳ 卸载中…]`（红色调）

### 6.8 卸载完成（688×584）

同「安装完成」：
- `「{产品名}」卸载完成` / `已从你的电脑中移除，共删除 N 个文件，释放 X MB 磁盘空间。`
- 绿色 chips：`✓ 程序文件已删除` `✓ 快捷方式已移除` `✓ 注册表已清理`
- **保留提示卡**（`#F5F7FA`）：`保留了用户配置目录` + `%APPDATA%\... （约 2.1 MB），如需彻底清理可手动删除。` + `[📁 打开目录]`
- 底栏：`第 3 步，共 3 步 · 卸载已完成` + `[⬇ 重新安装] [完成 ✓]`

## 8. 与当前实现的差距

当前 `Installer.UI` 的向导是**完全另一套**：

| 项 | 当前 | 设计稿 |
|---|---|---|
| 标题栏 | 系统原生 | 无（窗口无边框，头部卡片自带品牌区） |
| 头部 | 一整条纯蓝带，只有产品名+版本 | 蓝色卡片，图标块 + 产品名 + 副标题 |
| 步骤指示 | 无（或简单文字） | **5 步圆点连线步骤条** |
| 页面数 | 6（Welcome/License/Path/Options/Installing/Finish） | **5**（Path + Options 合并为「安装设置」） |
| 背景 | 纯白 | 灰底 + 白圆角卡片 + 阴影 |
| 卸载 | 3 页 | 3 页（结构对齐） |

**关键重构**：`WizardPage` 枚举要把 `Path` + `Options` 合并成一个 `Settings`，
状态机、Presenter、单测、e2e 断言都要跟着改。
